# Boxing Hub — Train with your body

Real-time boxing training games powered by MediaPipe pose detection + Random Forest classifier.

**Your webcam is the controller.** Three mini-games:
- **Memory** — memorise a punch combo then throw it
- **Combo Rush** — beat the clock throwing combos
- **Defense Drill** — read the incoming attack and throw the right counter

## Setup
- Stand ~2m from webcam
- Good front lighting, full upper body visible
- Allow camera access when prompted
